# Макеты

Экспорт разметки с холста «inrenta — сравнение прокатов» в Claude Design (23 сен 2026).

- `HomeB.dc.html`, `CompareB.dc.html`, `MobileB.dc.html` — **вариант Б, целевой**.
- `variant-A/` — первый вариант: там же есть экраны, которых пока нет в Б (категория, профиль проката,
  кабинет, страница для курьеров). Перерисовать их в стиле Б по `DESIGN_SYSTEM.md`.
- `variant-A/standalone-prokat-perforatora.html` — обычная HTML-страница, открывается в браузере как есть.

Файлы `.dc.html` — формат Claude Design (`<x-dc>`, `<sc-for>`, `<sc-if>`, `{{…}}`). В браузере напрямую
не запускаются; используй их как точную разметку: структура блоков, размеры, цвета, тексты — в инлайн-стилях.
Логика вкладок и калькулятора — в блоке `<script type="text/x-dc">` внизу файла, её эталон — `code/pricing.ts`.

Данные в макетах вымышленные, кроме экрана курьеров (`variant-A/Courier.dc.html`): там реальные цены
сентябрьского сбора 2026, залоги двух прокатов не выяснены.
