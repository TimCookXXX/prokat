# Дизайн-система inrenta (вариант Б)

Источник: холст «inrenta — сравнение прокатов» в Claude Design, ряд «Вариант Б».
Токены в коде — `design/tokens.css` (CSS-переменные) и `design/tailwind.preset.ts`.

## Принципы

1. **Итог, а не цена за сутки.** Крупнее всего на экране — сумма за даты пользователя.
   Расшифровка («900 ₽ аренда + 400 ₽ доставка») — мелко под ней.
2. **Свежесть видна всегда.** У каждой цены дата проверки. Цены старше 30 дней не ранжируются.
3. **Нейтральность.** Не «переплата», а «на 700 ₽ дешевле самого дорогого». Реклама, когда появится, помечается.
4. **Один акцент.** Оранжевый — только победитель вкладки и главная кнопка. Всё остальное — зелёный и нейтральные.
5. **Механика поисковиков билетов, свой вид.** Берём способ сравнения (поиск, вкладки, фильтры с ценами, «билет»),
   но не цвета, логотип и иллюстрации Aviasales.

## Цвета (светлая тема)

| Токен | Hex | Где |
| --- | --- | --- |
| `--c-ground` | `#EEF3F1` | Фон страницы, фон чипов на белом |
| `--c-surface` | `#FFFFFF` | Карточки, поиск, вкладки |
| `--c-brand` | `#0F3D35` | Шапка, выбранная вкладка, вторичные кнопки |
| `--c-brand-text` | `#CFE3DD` | Вторичный текст на `--c-brand` |
| `--c-ink` | `#16201D` | Основной текст |
| `--c-muted` | `#56645F` | Подписи, расшифровки (контраст на белом ≈ 6:1) |
| `--c-line` | `#DDE5E2` | Разделители, пунктир «билета» |
| `--c-line-strong` | `#C9D6D1` | Контурные кнопки, пунктирные блоки |
| `--c-accent` | `#C24A06` | Заливка главной кнопки (белый текст ≈ 4.6:1), подпись победителя |
| `--c-accent-bright` | `#FF8A3D` | Только декор на тёмном: точка в логотипе, галочки в шапке |
| `--c-accent-soft` | `#FFF1E6` | Подсказка «как сэкономить», промокод |
| `--c-ok` / `--c-ok-soft` | `#0E6B5F` / `#DDF0EC` | «Подтвердил цены», «привезут сегодня» |
| `--c-warn` / `--c-warn-soft` | `#8A5800` / `#FBF0D6` | «от 3 суток», «цена на перепроверке», «уточняется» |
| `--c-photo` | `#DDE8E4` | Заглушка фото |

Почему не `#E0560B` для кнопок: белый текст на нём не проходит контраст 4.5:1 на 15–16px. Яркий оранжевый — только без текста.

Тёмная тема в `tokens.css` — черновик, в макетах её нет. Перед запуском нарисовать.

## Типографика

Шрифты: **Unbounded** (600–700) — логотип, H1, цены. **Onest** (400–700) — всё остальное. Оба с кириллицей, Google Fonts / `next/font`.
Цифры — `font-variant-numeric: tabular-nums`.

| Роль | Шрифт | Размер / вес |
| --- | --- | --- |
| Логотип | Unbounded | 20–21 / 700, точка `--c-accent-bright` на тёмном, `#E0560B` на светлом |
| H1 главной | Unbounded | 50 / 600, межбуквенный −0.02em |
| H1 страницы | Unbounded | 28 / 600 (телефон 24) |
| H2 секции | Unbounded | 26 / 600 |
| Цена в «билете» | Unbounded | 30 / 600 (телефон 26 у победителя, 24 у остальных) |
| Цена во вкладке и карточке категории | Unbounded | 17–20 / 600 |
| Название проката | Onest | 18 / 600 (телефон 16) |
| Текст | Onest | 15 / 400 |
| Вторичный текст | Onest | 14 / 400, `--c-muted` |
| Подписи, расшифровка итога | Onest | 12–13 / 400, `--c-muted` |
| Подпись поля в поиске | Onest | 11–12 / 400, `--c-muted` |
| Заголовок группы фильтров | Onest | 15 / 700 |

## Размеры

- Шаг отступов 4: 4 · 8 · 12 · 16 · 20 · 24 · 28 · 32 · 48 · 64.
- Поля страницы: 64 на десктопе, 16 на телефоне. Колонка фильтров 260, зазор 28.
- Радиусы: 6 бейдж · 8 чип · 10 кнопка · 12 поле, мобильная карточка-плитка · 14 компактный поиск, контейнер вкладок · 16 «билет», карточка · 18 поиск на главной.
- Тень карточки: `0 1px 2px rgba(15,61,53,.06), 0 8px 24px -16px rgba(15,61,53,.25)`. Тень поиска на главной: `0 20px 40px -24px rgba(0,0,0,.5)`.
- Высота кнопок ≥44, на телефоне 46.

## Компоненты

### SearchBar
Белая плашка, три поля через вертикальные разделители: **Что нужно · Когда · Куда привезти**, справа кнопка «Найти» (`--c-accent`).
Под плашкой на главной — галочки «Заберу сам», «Без денежного залога».
Варианты: большой (главная, радиус 18, значения 19/600) и компактный (страница сравнения, радиус 14, значения 16/600).
Телефон: одна строка-кнопка «Перфоратор SDS-plus / сб 27 — пн 29 сен · привезти в ФМР» с иконкой карандаша, по нажатию — полноэкранная форма.
«Когда» — выбор диапазона дат, не счётчик дней. Из дат считаем число суток.

### ResultTabs
Три равные вкладки в белом контейнере: **Самый дешёвый · Без денежного залога · Привезут сегодня**.
В каждой: название (13/600), цена лучшего (Unbounded 20), кто это (12). Выбранная — заливка `--c-brand`, текст белый.
Каждая вкладка — это фильтр + сортировка по итогу, а не просто сортировка.

### OfferTicket («билет»)
Две части через вертикальный пунктир 2px `--c-line` с полукруглыми вырезами сверху и снизу (цвет фона страницы).
- Левая (240px): подпись победителя вкладки (12/700, `--c-accent`, только у первого) · итог (Unbounded 30) · расшифровка (12) · кнопка «Показать телефон».
- Правая: название + бейдж «Подтвердил цены» · строка «модель · район · когда привезут» · чипы «Залог …», «от N суток», «… за неделю», «Цена проверена …» · фото 88×88.
- Кнопка: у победителя `--c-accent`, у остальных `--c-brand`. После нажатия — номер (17/700) и «Скажите, что нашли на inrenta».
- Состояния: минимальный срок >1 суток — чип в `--c-warn`; «сегодня» — текст в `--c-ok`; залог «уточняется» — `--c-warn`.
- Телефон: вертикально, пунктир горизонтальный, итог сверху слева, фото 64×64 справа.

### FiltersSidebar
Группы: Залог · Получение · Прокат · Район проката. Каждый вариант: чекбокс, название, справа **минимальная цена при этом фильтре** («Без денежного залога — от 1 350 ₽»).
Внизу — короткая справка по выбору класса («SDS-plus 2–4 Дж — дюбели…»).
Телефон: кнопка «Фильтры · N» открывает полноэкранный лист.

### SavingsHint
Плашка `--c-accent-soft`, радиус 12: «Нужен на неделю? У «Инструмента у дома» — 2 400 ₽ за 7 дней вместо 3 150 ₽». Показываем, когда недельный тариф выгоднее суточной цены × 7 больше чем на 10%.

### RecheckBlock и PickupOnlyBlock
Пунктирные блоки под списком: «Цена на перепроверке — не ставим в рейтинг, пока не подтвердим звонком» и «Только самовывоз — отметьте «Заберу сам», чтобы сравнить».

### CategoryCard (главная)
Фото 150px сверху, внизу название (18/600) + число прокатов слева, «от / 350 ₽ / в сутки» справа.

### Бейджи и чипы
- Бейдж «Подтвердил цены»: `--c-ok-soft` фон, `--c-ok` текст, иконка галочки, радиус 6.
- Чип условия: `--c-ground` фон на белом, 13px, радиус 8.
- Предупреждение: `--c-warn-soft` + `--c-warn`.

### Иконки
Линейные, stroke 2, скруглённые концы, 16–22px. Никаких эмодзи.

## Тексты

- Со стороны пользователя, коротко: «Итог за ваши даты», «Показать телефон», «Цена устарела?», «Заберу сам».
- «Прокат» или «аренда» в заголовках — по данным Wordstat для каждой категории: инструмент и коляски → «прокат», прицепы и спецтехника → «аренда».
- Запрещено: «аренда у соседей», «берите у людей рядом», любые P2P-формулировки.
- Числа: пробел-разделитель тысяч, «₽» через пробел, «от 3 суток», даты «27 сен».

## Доступность

Настоящие `<button>`, `<a>`, `<input>` + `<label>`. Фокус виден. Текст ≥4.5:1, крупный ≥3:1. Касания ≥44px.
