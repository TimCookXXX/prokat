# inrenta: разворот в сравнение цен прокатов

Пакет для переделки текущего проекта (Next.js 15 · Drizzle · PostgreSQL).
Положи папку `inrenta-pivot/` в корень репозитория, например в `docs/inrenta-pivot/`,
и открой проект в VS Code. Если работаешь с AI-ассистентом, начни с `AGENT_PROMPT.md`.

## Что внутри

| Файл | Зачем |
| --- | --- |
| `PRODUCT.md` | Суть продукта, модель денег, стадия, метрики, чего не делаем |
| `DESIGN_SYSTEM.md` | Дизайн-система варианта Б: принципы, токены, компоненты, тексты |
| `MIGRATION.md` | Что в текущем проекте оставить, что спрятать, что написать заново, по шагам |
| `DATA_MODEL.md` | Новые таблицы и почему они отдельные от объявлений |
| `AGENT_PROMPT.md` | Готовый промпт для Claude Code / Copilot в VS Code |
| `design/tokens.css` | CSS-переменные: цвета, шрифты, радиусы, тени (светлая + черновик тёмной) |
| `design/tailwind.preset.ts` | Те же токены для Tailwind, если он в проекте |
| `code/schema.aggregator.ts` | Черновик Drizzle-схемы новых таблиц |
| `code/pricing.ts` | Расчёт итога, ранжирование, вкладки — чистые функции с типами |
| `code/pricing.test.ts` | Тесты расчёта (vitest) |
| `data/offers.template.csv` | Шаблон таблицы для ручного сбора цен (этап 1 плана) |
| `mockups/` | Разметка макетов из Claude Design как визуальный ориентир |

## Главное в одной фразе

inrenta — не маркетплейс, а сравнение: собираем цены и условия **всех** прокатов города
и показываем **итоговую сумму за даты пользователя** у каждого проката. Деньги — с прокатов
за обращения клиентов.

## Какой вариант дизайна делаем

Вариант **Б** (поиск «что · когда · куда», вкладки, фильтры, карточки-билеты).
Файлы с суффиксом `B` в `mockups/` — целевые. Остальные — вариант А, для справки
(экраны профиля проката, кабинета, категории и курьеров пока есть только в варианте А —
их нужно перерисовать в стиле Б по `DESIGN_SYSTEM.md`).
