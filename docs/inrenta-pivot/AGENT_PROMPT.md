# Промпт для AI-ассистента в VS Code

Скопируй текст ниже в Claude Code (или другого ассистента), открыв репозиторий проекта.

---

Мы переделываем проект inrenta из P2P-маркетплейса аренды в сервис сравнения цен прокатов.
Всё описание лежит в `docs/inrenta-pivot/`. Прочитай в таком порядке: `README.md`, `PRODUCT.md`,
`MIGRATION.md`, `DATA_MODEL.md`, `DESIGN_SYSTEM.md`, затем `code/`, `design/`, `mockups/`.

Правила работы:
1. Сначала изучи текущий проект: структуру `app/`, схему Drizzle, авторизацию, как сделаны стили
   (Tailwind, CSS Modules или другое), формат id в таблицах. Ничего не меняй, пока не покажешь мне
   короткий отчёт и план по шагам из `MIGRATION.md` с учётом того, что нашёл.
2. Каркас (Next.js, Drizzle, авторизация, деплой, маршруты городов) оставляем.
   Старые P2P-функции (объявления пользователей, календарь, заявки с подтверждением, чаты) не удаляем —
   прячем за флагом `FEATURE_P2P`.
3. Новые сущности — новые таблицы из `code/schema.aggregator.ts`. Таблицу объявлений не переделываем в предложения.
4. Расчёт итога — только через `code/pricing.ts` (перенести в `lib/pricing.ts` вместе с тестами).
5. Стили — токены из `design/tokens.css` или пресет `design/tailwind.preset.ts`, в зависимости от того,
   что уже используется. Не добавляй второй подход к стилям.
6. Визуальный ориентир — `mockups/*B.dc.html` (вариант Б). Это не рабочий код, а разметка с инлайн-стилями:
   переноси структуру и значения, не теги `<x-dc>`, `<sc-for>`, `<sc-if>`.
7. Тексты — по разделу «Тексты» в `DESIGN_SYSTEM.md`. Никаких «аренда у соседей».
8. Работай шагами из `MIGRATION.md`, после каждого шага — короткий отчёт и что проверить руками.

Начни с шага 0: отчёт о текущем проекте и план.
