# Как заполнять прокаты

Шаблон — `prokaty.template.csv`. Открывается в Numbers, Excel или Google Таблицах.

**Одна строка — одна вещь в прокате.** Нашли прокат — заполните первую строку целиком.
Для следующих вещей того же проката оставьте «Прокат», «Адрес» и «Телефон» пустыми:
они возьмутся из строки выше.

| Колонка | Как писать | Обязательно |
|---|---|---|
| Прокат | название, как на вывеске или сайте | да, в первой строке проката |
| Адрес | `ул. Красная, 120` — координаты найдутся сами | желательно |
| Телефон | в любом виде: `8 900 123-45-67`, `+79001234567` | желательно |
| Что сдают | обычными словами: `моющий пылесос`, `болгарка 125`, `перфоратор sds-max` | да, если нет модели из справочника |
| Модель | как написано у проката: `Karcher Puzzi 8/1`, `Макита 2470` | нет |
| Цена за сутки | `1000`, `1 000 ₽` | да (или цена за неделю) |
| Цена за неделю | так же | нет |
| Минимум суток | `2`; пусто — 1 сутки | нет |
| Залог | `3000`, `паспорт`, `3000 + паспорт`, `нет`; **пусто — «уточняется»** | нет |
| В комплекте | `моющее средство`, `2 бура` | нет |
| Часы работы | `пн-пт 9-20; сб 10-16; вс выходной`, `ежедневно 9-21`, `круглосуточно` | нет |
| Ссылка | где нашли цену: сайт, Авито, Телеграм | нет |
| Проверено | `26.09.2026`; пусто — сегодня | нет |

Если «Что сдают» подходит под несколько вещей («перфоратор» — SDS-plus или SDS-max),
импорт попросит уточнить. Строки с названием «ПРИМЕР …» не загружаются.

**Сохранить:** Numbers — «Файл → Экспортировать → CSV» (кодировка UTF-8); Excel —
«CSV UTF-8»; Google Таблицы — «Файл → Скачать → CSV». Разделитель — запятая или точка
с запятой, неважно.

**Загрузить:** `pnpm db:import-offers файл.csv --dry-run` (проверка), затем без
`--dry-run`. Полный шаблон со всеми полями (доставка, координаты) — `offers.template.csv`.
